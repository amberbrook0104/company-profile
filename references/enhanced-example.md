# 品牌增强版案例

公开展示采用用户确认的五粮液增强版，文件为 `examples/wuliangye/company-profile-enhanced.html` 与同名PNG。它是专业公司一页概览，素材已嵌入网页。

制作步骤：先用脚本取得并核实财务底稿，再从公司官网获取Logo、品牌参考色和真实产品/实景素材；根据公司自身信息整理六个模块：公司概况、营收结构、核心产品与相关经营资源、销售区域分布、财务摘要、业绩趋势与股权结构。

地域数据按公司披露粒度呈现。本案例的地图依据2025年报第13页三个酒类销售片区的营收，气泡中心仅示意方向，不代表省级销售额；四川与宜宾点位标注总部，不代表全国生产基地。没有相应数据的其他公司不应复制该地图。

来源记录：

- 官网及品牌素材：https://www.wuliangye.com.cn/zh/main/index.html
- 2025年报：https://static.cninfo.com.cn/finalpage/2026-04-30/1225273091.PDF
- 2026半年报：https://static.cninfo.com.cn/finalpage/2026-08-29/1225531252.PDF
- 地图边界：https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json

股票、财报与估值日期沿用案例快照，不把增强排版日期当作数据更新日期。数据及第三方素材仅用于该公司介绍案例，第三方权利不因软件MIT许可而转移。

命令行基础模板仍可用于数据验证和快速底稿。要生成类似增强案例的成品，Agent应参考案例内的HTML/CSS，按新公司的素材、数据、内容量重新布局，完成图片导出和视觉检查。
